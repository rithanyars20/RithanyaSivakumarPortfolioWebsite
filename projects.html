Port Congestion Data Pipeline: End-to-end data pipeline for analyzing global port congestion trends

Skills: Python, DuckDB, SQL, dbt, GitHub Actions

Description:

  • Built and maintained an end-to-end data pipeline using Python and IMF PortWatch AIS shipping data, ingesting global port activity into DuckDB and transforming raw data into analysis-ready datasets.
  • Developed dbt SQL models to standardize source data, transform daily activity into weekly metrics, and compare port arrivals against a rolling four-week historical baseline to identify unusual activity.
  • Implemented data-quality tests for null values, negative ship counts, duplicate port/date records, and invalid identifiers; investigated and resolved source-data parsing issues caused by quoted commas.
  • Automated recurring pipeline execution using GitHub Actions on Ubuntu Linux, refreshing analytical datasets and exporting version-controlled results for downstream analysis and reporting.
